ABOUT THE ATLAS / PKK

เรื่องราวของ
ไดเรกทอรี

พื้นที่กลางสำหรับค้นพบสถานที่ ร้านค้า บริการ และเรื่องราวท้องถิ่นของจังหวัดประจวบคีรีขันธ์

← กลับหน้าหลัก
PURPOSE

สร้างแผนที่ที่ค้นพบได้

เว็บไซต์นี้ออกแบบให้คนในพื้นที่และผู้มาเยือนค้นหาสถานที่ตามชื่อ หมวดหมู่ และพื้นที่ได้ง่ายในหน้าเดียว

PRINCIPLE

ข้อมูลชัดเจน ใช้งานง่าย

ทุกหน้าถูกจัดวางให้เห็นข้อมูลสำคัญก่อน พร้อมลิงก์แผนที่ ช่องทางติดต่อ และรายละเอียดที่ช่วยตัดสินใจ

NOW

เปิดดูได้ทุกที่

เวอร์ชันปัจจุบันเป็น static website บน GitHub Pages จึงเปิดดูได้โดยไม่ต้องติดตั้ง XAMPP, PHP หรือ MySQL

PROJECT NOTES

พัฒนาการของเว็บไซต์

01 / START

รวมข้อมูลสถานที่ในจังหวัด

เริ่มจากแนวคิดไดเรกทอรีที่ทำให้สถานที่ท้องถิ่นถูกค้นพบได้จากคำค้นและหมวดหมู่ที่เข้าใจง่าย

02 / ORGANIZE

จัดกลุ่มตามเส้นทางและประเภท

เพิ่มโครงสร้างการกรองข้อมูลตามหมวดหมู่ อำเภอ ตำบล สถานะบริการ ช่วงราคา และคะแนนรีวิว

03 / PUBLISH

เผยแพร่บน GitHub Pages

ปรับระบบให้ใช้ข้อมูล static ฝั่งเบราว์เซอร์ พร้อมรองรับ project path ของ repository และการเปิดเส้นทางภายใน

หมายเหตุ: ข้อมูลตัวอย่างในไดเรกทอรีมีไว้เพื่อสาธิตโครงสร้างเว็บไซต์ ควรตรวจสอบและแทนที่ด้วยข้อมูลที่ได้รับอนุญาตก่อนใช้งานเชิงธุรกิจ
