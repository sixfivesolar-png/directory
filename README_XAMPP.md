# การนำเว็บไซต์ประจวบคีรีขันธ์ Directory ไปใช้กับ XAMPP

เว็บไซต์นี้เป็น **Static React Website** เมื่อ build แล้วจะได้ไฟล์ HTML, CSS, JavaScript และรูปภาพในโฟลเดอร์เดียวกัน ซึ่ง Apache ของ XAMPP สามารถเปิดได้โดยไม่ต้องใช้ PHP, MySQL หรือ Node.js บนเครื่องที่นำไปใช้งาน

## ขั้นตอนติดตั้ง

แตกไฟล์ `prachuap-directory-xampp.zip` แล้วคัดลอกโฟลเดอร์ `prachuap-directory` ไปไว้ที่ `C:\\xampp\\htdocs\\` โดย **คงชื่อโฟลเดอร์ `prachuap-directory` ไว้ตามเดิม** จากนั้นเปิด Apache ใน XAMPP Control Panel แล้วเข้าผ่าน URL `http://localhost/prachuap-directory/`

| สิ่งที่ต้องทำ | ตำแหน่งหรือผลลัพธ์ |
|---|---|
| แตกไฟล์ ZIP | จะได้โฟลเดอร์ `prachuap-directory` |
| คัดลอกโฟลเดอร์ | `C:\\xampp\\htdocs\\prachuap-directory` |
| เปิด Apache | จาก XAMPP Control Panel |
| เปิดเว็บไซต์ | `http://localhost/prachuap-directory/` |

หน้า Search และหน้ารายละเอียดใช้เส้นทางแบบ `http://localhost/prachuap-directory/search` และ `http://localhost/prachuap-directory/place/krua-thale-ao-noi` โดยไฟล์ `.htaccess` ที่อยู่ในแพ็กเกจจะส่งเส้นทางเหล่านี้กลับมาที่หน้า Static หลักของเว็บไซต์

## เปิดใช้ Google Maps และรีวิวด้วย MySQL

เปิด Apache และ MySQL ใน XAMPP จากนั้นเข้า phpMyAdmin และ import ไฟล์ `database/schema.sql` ในโฟลเดอร์เว็บไซต์เพื่อสร้างฐานข้อมูล `prachuap_directory` และตารางรีวิว ระบบจะเริ่มต้นด้วย **ไม่มีคะแนนและไม่มีรีวิว** จนกว่าผู้ใช้จะส่งความคิดเห็นจริงผ่านหน้าแสดงรายละเอียด

ไฟล์ `api/config.php` ใช้ค่าเริ่มต้นของ XAMPP คือ MySQL ผู้ใช้ `root` และรหัสผ่านว่าง หากเครื่องของคุณตั้งค่าต่างออกไป ให้แก้ไขไฟล์นี้ก่อนใช้งาน Google Maps ในหน้ารายละเอียดจะแสดงตำบล/อำเภอเป็นจุดอ้างอิง และควรเติมละติจูด-ลองจิจูดที่ยืนยันแล้วในตาราง `places` ก่อนแสดงเป็นตำแหน่งสถานที่จริง

## เปิดใช้ผู้ดูแล ผู้ประกอบการ และ CAPTCHA

หลัง import `database/schema.sql` ให้สมัครบัญชีผ่านหน้า `/login` ก่อน จากนั้นเปิด `database/promote_admin.sql.example` แก้ไขอีเมล แล้วนำคำสั่ง `UPDATE` ไปรันใน phpMyAdmin เพื่อกำหนดบัญชีแรกเป็นผู้ดูแล ระบบไม่มีบัญชีผู้ดูแลหรือผู้ประกอบการที่สร้างไว้ล่วงหน้า

หากคุณติดตั้งเว็บรุ่นก่อนหน้าที่มีตารางรีวิวอยู่แล้ว ให้สำรองฐานข้อมูลก่อน แล้ว import `database/upgrade_auth.sql` ตามด้วยตรวจสอบตาราง `users`, `business_claims` และ `business_updates` จาก `schema.sql` ใน phpMyAdmin ก่อนเปิดใช้ระบบใหม่

ผู้ดูแลใช้หน้า `/admin` เพื่ออนุมัติหรือซ่อนรีวิว ตรวจคำขอ Claim Business และคำขอแก้ไขข้อมูล เจ้าของธุรกิจต้องเข้าสู่ระบบ กด “Claim Business” ในหน้ารายละเอียด และรอผู้ดูแลอนุมัติก่อนใช้หน้า `/business` ได้ รีวิวต้องเข้าสู่ระบบ ตอบ CAPTCHA และรออนุมัติก่อนแสดงในหน้าสาธารณะ

## สมาชิกเสนอข้อมูลสถานที่

ปุ่ม **เพิ่มสถานที่** จะพาผู้ที่ยังไม่ได้เข้าสู่ระบบไปสมัครสมาชิกก่อน สมาชิกสามารถส่งข้อมูลสถานที่ได้ครั้งละ **1 รายการที่กำลังรอตรวจสอบ** เท่านั้น หลังผู้ดูแลอนุมัติหรือปฏิเสธแล้วจึงส่งรายการถัดไปได้ รายการที่อนุมัติจะถูกสร้างเป็นระเบียนในไดเรกทอรีและแสดงผลบนหน้า Search/รายละเอียดโดยอัตโนมัติ

ระดับผู้ร่วมข้อมูลนับจากจำนวนสถานที่ที่ผู้ดูแลอนุมัติจริง: ผู้ร่วมข้อมูลใหม่ (0), ผู้ร่วมข้อมูลท้องถิ่น (1), นักทำแผนที่ชายฝั่ง (3) และผู้พิทักษ์แอตลาส (10) หากติดตั้งบนฐานข้อมูลเดิม ให้ import `database/upgrade_member_place_submissions.sql` หลังสคริปต์อัปเกรดเดิม แล้วผู้ดูแลตรวจคำขอจากหน้า `/admin`

## ไฟล์หลักฐานและ Dashboard เจ้าของธุรกิจ

คำขอ Claim Business ต้องแนบหลักฐานอย่างน้อย 1 ไฟล์ และแนบได้ไม่เกิน 3 ไฟล์ โดยรองรับ JPG, PNG, WEBP หรือ PDF ขนาดไม่เกิน 5 MB ต่อไฟล์ ไฟล์จะเก็บใน `storage/private-claims` ซึ่งถูกปิดการเข้าถึงโดยตรง และผู้ดูแลต้องเปิดผ่านหน้า `/admin` ที่ตรวจสิทธิ์แล้วเท่านั้น

ก่อนเปิดใช้งานอัปโหลด ให้ตรวจไฟล์ `php.ini` ของ XAMPP ว่ากำหนด `upload_max_filesize` อย่างน้อย `5M` และ `post_max_size` อย่างน้อย `16M` แล้ว restart Apache เพื่อให้ขนาดที่หน้าเว็บแจ้งตรงกับขีดจำกัดของ PHP

Dashboard ที่ `/business` จะแสดงยอดเข้าชมแบบรวมของหน้ารายละเอียดในช่วง 7 วัน, 30 วัน และตั้งแต่เริ่มบันทึก โดยไม่สร้างข้อมูลตัวอย่าง ระบบเริ่มนับเมื่อมีผู้ใช้เปิดหน้ารายละเอียดหลังติดตั้งแล้ว หากเป็นฐานข้อมูลเดิม ให้ import `database/upgrade_uploads_dashboard.sql` หลัง `upgrade_auth.sql` ก่อนใช้งาน

## คะแนนสมาชิกและ VIP

สมาชิกจะได้รับ **10 แต้มต่อหนึ่งรีวิวที่ผู้ดูแลอนุมัติ** เท่านั้น โดยหนึ่งรีวิวเครดิตได้เพียงครั้งเดียว หากผู้ดูแลซ่อนรีวิวภายหลัง ระบบจะอัปเดตยอดแต้มของรีวิวนั้นเป็นศูนย์ ผู้ใช้เริ่มต้นในระดับ Explorer, ได้ Gulf VIP ที่ 50 แต้ม, Coastal VIP ที่ 150 แต้ม และ Atlas VIP ที่ 300 แต้ม หน้า `/rewards` จะแสดงสถานะและประวัติแต้มจากรีวิวจริง โดยไม่มีแต้มตัวอย่าง หากใช้ฐานข้อมูลเดิม ให้ import `database/upgrade_loyalty.sql` หลัง `upgrade_auth.sql`

## คูปองแลกแต้ม กระดานผู้นำ และ QR หน้าร้าน

เจ้าของธุรกิจที่ผ่าน Claim Business แล้วใช้หน้า `/business` เพื่อเสนอคูปองของสถานประกอบการที่ตนได้รับสิทธิ์จัดการได้ โดยต้องระบุชื่อคูปอง รายละเอียด แต้ม จำนวนสิทธิ์ (ถ้ามี) และ **วันหมดอายุในอนาคต** ทุกคำขอมีสถานะ `pending_admin` และจะไม่ปรากฏในหน้าแลกแต้มจนกว่าผู้ดูแลจะอนุมัติจากหน้า `/admin` ผู้ดูแลยังสามารถสร้างคูปองของร้านค้าที่เข้าร่วมได้โดยตรง และต้องกำหนดวันหมดอายุเช่นเดียวกัน

สมาชิกใช้ **แต้มคงเหลือ** ในการแลกคูปอง แต่ระดับ VIP คำนวณจากแต้มรีวิวที่อนุมัติสะสมตลอดอายุ จึงไม่ลดระดับเมื่อใช้แต้ม คูปองหนึ่งรายการแลกได้หนึ่งครั้งต่อสมาชิก และระบบตัดแต้มแบบ transaction หน้า `/rewards` แสดง QR Code ของคูปองที่ยังใช้ได้ พร้อมป้ายเตือนเมื่อเหลือไม่เกิน 7 วัน และป้ายเร่งด่วนเมื่อเหลือไม่ถึง 24 ชั่วโมง

พนักงานหน้าร้านต้องเข้าสู่ระบบด้วยบัญชีเจ้าของธุรกิจที่มี Claim Business ของร้านนั้นแล้ว หรือบัญชีผู้ดูแล จากนั้นเปิด `/coupon-verify` เพื่อสแกน QR Code ผ่านกล้อง หรือกรอกรหัส `PKK-XXXXXXXXXXXXXXXX` ด้วยตนเอง ระบบจะตรวจสอบร้าน สถานะ และวันหมดอายุก่อนให้กดยืนยันการใช้สิทธิ์ เมื่อยืนยันแล้วคูปองจะเปลี่ยนเป็น `used` และไม่สามารถใช้ซ้ำได้ การใช้กล้องทำงานบน `localhost` โดยควรอนุญาตสิทธิ์กล้องในเบราว์เซอร์ หากเปิดผ่านชื่อโดเมนหรือ IP ในเครือข่าย ควรตั้งค่า HTTPS ก่อนใช้งานกล้อง

หน้า `/leaderboard` แสดงลำดับจากแต้มรีวิวสะสมหรือจำนวนรีวิวที่อนุมัติ โดยแสดงเฉพาะชื่อที่ผู้ใช้ตั้งไว้และไม่มีข้อมูลตัวอย่าง หากใช้ฐานข้อมูลเดิม ให้ import `database/upgrade_coupons_leaderboard.sql` หลัง `upgrade_loyalty.sql` แล้ว import `database/upgrade_owner_coupons_qr.sql` เป็นลำดับสุดท้ายก่อนเปิดใช้ฟีเจอร์นี้

## การแทนที่ข้อมูลตัวอย่าง

หน้าไดเรกทอรีมีรายการสถานที่ ข่าวสาร และอีเมลติดต่อเป็น **ข้อมูลตัวอย่าง** สำหรับแสดงโครงสร้างเท่านั้น ก่อนใช้งานจริงควรแทนที่ข้อมูลใน `client/src/pages/Home.tsx` ด้วยข้อมูลที่ได้รับอนุญาตจากเจ้าของสถานที่หรือหน่วยงานที่เกี่ยวข้อง แล้ว build และสร้าง ZIP ใหม่

ตัวกรองอำเภอและตำบลจัดโครงสร้างจากข้อมูลเขตการปกครองของสำนักงานท้องถิ่นจังหวัดประจวบคีรีขันธ์ [1]
